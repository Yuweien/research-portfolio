### SiWeaver


*A dialogue-driven interface for real-time cognitive structure visualization.*

SiWeaver explores how AI can support nonlinear thinking by continuously transforming dialogue, writing, or discussion into visual structures such as concept maps, argument maps, and knowledge networks.
